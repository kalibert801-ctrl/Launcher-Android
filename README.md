# AleksOS Launcher

Android-лаунчер (рабочий стол), в котором **Android-приложения и Windows-программы живут рядом**:
звонки, Telegram и всё остальное работают как обычно, а рядом лежат иконки `.exe`-программ.

## Что уже есть (версия 0.1)
- Рабочий стол со всеми Android-приложениями и поиском.
- Можно назначить рабочим столом телефона (кнопка «Домой»).
- Плитка **«Добавить .exe»**: выбираете `.exe` / `.msi` / `.bat` / `.lnk`, и программа появляется на рабочем столе с меткой `WIN`.
- Долгое нажатие: у Android-приложения открываются его настройки, Windows-программу можно убрать с рабочего стола.

Запуск Windows-программ пока **не работает**: движок (Wine + Box64 + DXVK/Turnip) подключается на следующих этапах.

## Как установить на телефон
1. Откройте вкладку **Releases** справа на странице репозитория (или **Actions** → последняя сборка → *Artifacts*).
2. Скачайте `AleksOS-Launcher-N.apk` и откройте его на телефоне.
3. Разрешите установку из этого источника, если Android спросит.
4. Чтобы сделать AleksOS рабочим столом: *Настройки → Приложения → Приложения по умолчанию → Главный экран → AleksOS*.

Каждая новая сборка ставится поверх старой, удалять приложение не нужно.

## План
1. ✅ Лаунчер с Android-приложениями и иконками Windows-программ.
2. ⬜ Движок: Wine + Box64, запуск одного `.exe`.
3. ⬜ Установка через `setup.exe`, иконки из самих `.exe`.
4. ⬜ Каждая Windows-программа в отдельном окне Android.
5. ⬜ Интеграция: общие папки, буфер обмена, «открыть с помощью».
6. ⬜ USB/COM-адаптеры (Вася Диагност, KKL на FTDI).

Целевой телефон для тестов: Motorola Edge 40 Pro (Snapdragon 8 Gen 2, Adreno 740, 12 ГБ).

## Сборка
APK собирается автоматически GitHub Actions при каждом push. Локально: `./gradlew assembleDebug` (нужен Android SDK).
