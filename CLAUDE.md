# AleksOS Launcher: контекст проекта

Общаться с владельцем на русском. Владелец не профессиональный программист, объяснять простыми словами.

## Цель
Android-лаунчер (рабочий стол), где **Android-приложения и Windows-программы живут рядом в одной сетке**.
Телефон остаётся обычным Android: звонки, Telegram и т. д. работают как всегда. Windows-программы
открываются по нажатию на иконку, как обычные приложения. Это НЕ виртуальная машина с Windows.

## Целевое устройство
Motorola Edge 40 Pro: Snapdragon 8 Gen 2 (SM8550), GPU Adreno 740, 12 ГБ ОЗУ, ARM64 (ARMv9), Android.
Adreno 7xx хорошо поддерживается драйвером Turnip (Mesa).

## Архитектура (принятые решения)
- **Лаунчер:** Kotlin, без AndroidX и сторонних библиотек, интерфейс строится в коде (без XML-разметки).
  Activity с категориями HOME + LAUNCHER.
- **Движок Windows (этап 2+):** стек как в Winlator: **Wine** (Windows API) + **Box64/Box86** (или FEX)
  для трансляции x86→ARM64 + **DXVK/VKD3D** (DirectX→Vulkan) + **Turnip** (Vulkan на Adreno),
  Linux-окружение через proot/chroot, X-сервер. Не писать с нуля: брать готовые компоненты, можно
  изучать/заимствовать код Winlator (GPL совместима с нашей лицензией GPL-3.0).
- Движок работает в foreground service (постоянное уведомление), держится «прогретым» для быстрого старта.
- **Каждая Windows-программа должна открываться как отдельная задача Android** (своё окно в «недавних»),
  а не в общем окне Windows, как в Winlator. Это ключевая и самая сложная фича.
- Точка входа в движок: `WindowsEngine.kt` (сейчас заглушка, `isAvailable = false`).

## Оформление (решения владельца)
- Рабочий стол «как Windows, но приспособленный под телефон». Расположение привычное (панель задач,
  меню «Пуск», окна с кнопками свернуть/развернуть/закрыть), но **внешний вид свой** (логотип «A»,
  свои цвета и иконки) — не копировать Windows, чтобы не было проблем с авторскими правами.
- Светлая тема: панель задач и «Пуск» — светлое «стекло»; окна — `AosDialog`, цвета в `Ui.kt`.
- Иконки на столе свободно перетаскиваются (`DesktopGrid.kt`), места хранятся в prefs.
- Всё своё AleksOS хранит в `/sdcard/AleksOS/` (Рабочий стол, Документы, Программы; позже «Диск C» для Wine).
  Рабочий стол = папка `AleksOS/Рабочий стол`: её файлы и папки видны на столе.
- Проводник «Этот телефон» — `ExplorerActivity` (своя задача в «недавних», окно можно уменьшить и
  двигать, свёрнутое показывается на панели задач). Нужен доступ «ко всем файлам».
- Самообновление из GitHub Releases (`Updater.kt`): versionCode = номер сборки Actions.
- Владелец смотрит работу через Remote Control с телефона: кнопки-вопросы и картинки там не видны,
  поэтому вопросы задавать обычным текстом.

## Этапы
1. ✅ Лаунчер: Android-приложения, поиск, плитка «Добавить .exe», Windows-программы с меткой WIN.
2. ⬜ Движок: Wine + Box64, запуск одного `.exe` из лаунчера.
3. ⬜ Установка через `setup.exe`, автоматические иконки (извлекать из ресурсов .exe/.lnk).
4. ⬜ Отдельное окно Android на каждую Windows-программу.
5. ⬜ Интеграция: общие папки телефона как диск D:, общий буфер обмена, «открыть с помощью».
6. ⬜ USB/COM через OTG для диагностики авто.

## Программы, которые владелец хочет запускать
- Игры: GTA Vice City, GTA San Andreas, C&C Generals / Zero Hour, Red Alert, Казаки.
  Старые диски с защитой SecuROM/SafeDisc не работают; лучше GOG/Steam или no-CD версии.
- **Вася Диагност** (диагностика VAG). Нужен драйвер адаптера. План: своя прослойка `ftd2xx.dll`
  внутри Wine, которая передаёт команды в USB-адаптер через Android USB Host API (OTG).
  Реально для KKL-шнуров на FTDI; оригинальные HEX-V2/HEX-CAN с защищённым протоколом, скорее всего, нет.
- Программы с драйверами ядра и античитами в принципе не запустятся, не тратить на них время.

## Сборка и выпуск
- GitHub: `kalibert801-ctrl/Launcher-Android`, лицензия GPL-3.0.
- GitHub Actions (`.github/workflows/build.yml`) собирает APK на каждый push.
  Из ветки `main` APK публикуется в Releases (тег `build-N`), владелец качает его на телефон оттуда.
- Подпись: фиксированный отладочный ключ `app/debug-signing.keystore` (пароль `android`),
  чтобы новые сборки ставились поверх старых. Он не секретный и специально лежит в репозитории.
- AGP 8.7.3, Kotlin 2.0.21, Gradle 8.14.3, compileSdk/targetSdk 35, minSdk 26, Java 17.
- Локальная сборка: `./gradlew assembleDebug` (нужен Android SDK / Android Studio).
- Папка проекта у владельца: `C:\Users\kalib\OneDrive\Desktop\Launcher-Android` (синхронизируется
  с OneDrive). Если начнутся проблемы со сборкой из-за блокировки файлов, предложить перенос вне OneDrive.
